## Reporting a Vulnerability

**Do not open a public GitHub issue for security vulnerabilities.**

Please report security issues by emailing:
**kumbam.nithingoud@gmail.com**

Include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact

You will receive a response within **48 hours**. We take all security reports seriously and will coordinate a fix and disclosure timeline with you.

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.2.x   | ✅ Yes     |
| 0.1.x   | ⚠️ Best-effort |
| < 0.1   | ❌ No      |
